Repair a PDF – rescue the file that will not open.

An interrupted download, a broken attachment or an error message in the reader? Retypee reads the file the forgiving way, rebuilds the structure and saves a clean copy.

  • No credit card
  • No sign-up
  • Unlimited use

How to repair a PDF

  1. Open the broken PDF.

    Retypee checks whether the file is damaged and how many pages can be read.

  2. Repair.

    The structure is rebuilt from the pages that are left.

  3. Download.

    You get a new, clean PDF that opens as usual.

What can be repaired

  • Files that were cut short, for example by an interrupted download or transfer.
  • Files with a broken index (xref) that readers complain about.
  • Files saved by programs with bugs.

What cannot be repaired

  • Pages whose content is missing altogether. You get the pages that can be read.
  • Files that are not PDFs, or that are completely destroyed.
  • Password-protected files first need unlocking with Unlock PDF.

Good to know

  • The original is never changed. You download a copy.
  • If the file is not damaged you still get a clean, rewritten copy, sometimes with a smaller file size.
  • If you want to make it smaller still, use Compress PDF.
  • The PDF engine (about 25 MB) is downloaded the first time you use the tool.

Questions about repairing PDFs

How do I repair a PDF that will not open?

Open the file here and click Repair and save. Retypee rebuilds the file and you download a working copy.

Can every broken PDF be repaired?

No. If the file was cut short or has a broken structure it often works, but pages whose content is missing cannot be brought back.

Is my original file changed?

No. You get a new copy and the original is not touched.

Is the file uploaded?

No. Everything happens in your browser and the file never leaves your computer.
