Change text in a PDF – without recreating it.

Found a typo, a wrong date or a wrong amount? Open the PDF, click the line and type it right. The rest of the page stays untouched.

The editor (about 25 MB) loads the first time you use it, then it is cached.

How to change text in a PDF

  1. Open the PDF.

    Drop it on the page. Every editable line is highlighted when you hover over it.

  2. Click the line and type.

    Type the new text and press Enter. Retypee uses the same font, size and colour as the original when it can.

  3. Download.

    Save the changed PDF. Everything else on the page – images, lines and links – stays as it was.

What you can change

  • Words and sentences, such as a typo or a wrong name.
  • Numbers, dates and amounts.
  • The font, size and colour of a line.
  • New text anywhere on the page with Add text.

How it works under the hood

A PDF does not store paragraphs, only characters at fixed positions. When you change a line, Retypee removes exactly those characters and writes the new text on the same baseline, with the same size and colour. Images, backgrounds and lines under the text are left alone.

Limits

  • Text does not reflow: a longer line runs further to the right. Use Squeeze to fit or shorten it.
  • Scanned PDFs contain only pictures and need OCR first.
  • Password-protected PDFs have to be unlocked first.

Questions about changing text in a PDF

How do I change text in a PDF for free?

Open the file in Retypee, click the line you want to change, type the new text and download the result. It costs nothing, needs no account and puts no watermark on the pages.

Can I change text in a PDF without uploading it?

Yes. Retypee runs in your browser, so the file is opened and changed in your device's memory and is never sent to a server.

Why does the text get a different font?

PDFs usually embed only the letters they use. If the original font lacks a letter you type, Retypee picks a similar built-in font. With Add font you can give it the original file for an exact match.

Can I change text in a PDF on my phone?

The tool works in modern mobile browsers, but it is made to be used with a mouse and keyboard.
