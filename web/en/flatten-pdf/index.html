Flatten a PDF – make comments and fields permanent.

After flattening, comments, highlights and filled-in form fields are part of the page and can no longer be changed. It suits a file you are about to send in or archive.

How to flatten a PDF

  1. Open the PDF.

    Retypee counts the comments and form fields in the file.

  2. Choose what to flatten.

    Comments and highlights, form fields, or both.

  3. Flatten and download.

    You get a new PDF where what you chose is part of the pages.

Why flatten

  • A filled-in form is going to be sent in and must not be changeable.
  • Highlights and comments should show in every reader and when printed.
  • The file is being archived in its final state.

How it differs from locking

A password or a restriction can be removed by anyone with the tools. Flattened fields are instead drawn on the page. The fields no longer exist, only what they showed. Whoever wants to change them has to edit the page itself.

Good to know

  • Flattening cannot be undone. Keep the original file if you need the fields again.
  • Links in the document are not affected.
  • If you have not filled in the form yet, use Fill in form first. It also has an option to flatten straight away.
  • Password-protected files have to be unlocked first, use Unlock PDF.
  • The PDF engine (about 25 MB) is downloaded the first time you use the tool.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about flattening PDFs

What does it mean to flatten a PDF?

Comments, highlights and form fields are drawn into the page itself. They look the same but can no longer be changed.

How do I flatten a filled-in form?

Open the file here, tick form fields and click Flatten PDF. You get a copy where the answers are fixed.

Can it be undone?

No. Keep the original file if you want to change the answers later.

Is the file uploaded?

No. Everything happens in your browser and the file never leaves your computer.
