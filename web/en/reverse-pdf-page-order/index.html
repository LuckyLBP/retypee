Reverse the page order of a PDF – or collate scans.

Last page first, or fronts and backs in the right sequence. Choose how the pages should be ordered and a new PDF is made right in your browser.

How to reverse the order of the pages

  1. Open the PDF.

    Drop it on the page.

  2. Choose the reordering.

    Reverse order, or collate fronts and backs.

  3. Create and download.

    You get a new PDF with the pages in the new order.

Reverse order

The last page becomes the first, the one before it becomes the second, and so on. It suits a document that was scanned or saved backwards, or a stack that has to be laid out in reverse.

Collate fronts and backs

If you have a double-sided original and only a single-sided scanner, you scan all the fronts first, flip the stack and scan the backs. The backs then end up in reverse order in the file. This option weaves them together: front 1, the last page, front 2, the one before last, and so on. The file needs as many fronts as backs.

Good to know

  • The content and size of the pages do not change, only the order.
  • If you want to move single pages or turn them, use Organize PDF.
  • If you scanned with a camera, start with Scan to PDF.
  • No pages are removed. For blank backs there is Remove blank pages.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about reversing PDF page order

How do I reverse the order of the pages in a PDF?

Open the file here, choose Reverse order and click Change the order. You download a new PDF with the last page first.

How do I put fronts and backs together from a scan?

Choose Collate fronts and backs. The file should have all the fronts first and all the backs in reverse order after them.

Why can my file not be collated?

It needs an even number of pages. If a page was missed in the scan, add a blank one first with Add blank pages.

Is the file uploaded?

No. Everything happens in your browser and the file never leaves your computer.
