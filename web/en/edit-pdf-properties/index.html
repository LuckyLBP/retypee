Edit PDF properties – title, author and keywords.

The title shows in the tab, in search results and in the file manager. See what the file contains now, change it and save. Everything happens in your browser.

How to change the properties of a PDF

  1. Open the PDF.

    The fields show what the file has now.

  2. Change the fields.

    Title, author, subject and keywords. Empty a field to remove the value.

  3. Save.

    You get a new PDF with the new properties.

Why it matters

  • The title shows in the browser tab and in search results, so a clear title looks better than a file name like final-v7.
  • The author and the program can reveal more than you want. Empty the fields before you share the file.
  • Keywords and subject help search in document management and archives.

Show the title in the window heading

Many readers show the file name in the tab even if the file has a title. If you tick Show the title in the window heading you ask the reader to show the title instead, which also makes the file more accessible.

Good to know

  • A separate XMP block, if there is one and some programs prefer it, is removed so that every program shows the same values.
  • If you want to clear everything, including dates and program name, use Remove metadata.
  • Accented letters such as é, ü and ñ work in every field.
  • The content of the pages is not affected.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about PDF properties

How do I change the title of a PDF?

Open the file here, type the new title in the Title field and click Save properties.

How do I remove the author name?

Empty the Author field and save. To clear everything at once there is Remove metadata.

Why does my reader still show the old details?

The file may have a separate XMP block with its own values. Retypee removes it when saving, so reload the new file.

Is the file uploaded?

No. Everything happens in your browser and the file never leaves your computer.
