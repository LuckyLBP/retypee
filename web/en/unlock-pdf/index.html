Unlock a PDF – remove the password.

Tired of typing the password every time? Enter it once and get a copy without one. Everything happens on your own device.

How to unlock a PDF

  1. Open the PDF.

    Retypee sees whether it needs a password or has restrictions.

  2. Type the password.

    If one is needed a field appears. If the file only has restrictions, such as against printing, no password is needed.

  3. Unlock and download.

    You get a copy without a password or restrictions.

Only for files you may open

If the file has a password you have to know it. The tool does not crack passwords. Use it for your own files or documents you have the right to change, and respect copyright and other people's restrictions.

What gets removed

  • The password to open the file, if you enter it.
  • Restrictions against printing, copying and editing.

Good to know

  • A wrong password gives a message and you can try again without starting over.
  • After unlocking, every other tool works, for example Merge PDF and Edit PDF.
  • The PDF engine (about 25 MB) is downloaded the first time you use the tool.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about unlocking PDFs

How do I remove the password from a PDF?

Open the file here, type the password and click Unlock PDF. You get a copy that opens without a password.

Can you unlock a PDF whose password I forgot?

No. The tool cannot guess or crack passwords. You have to know it.

Why can't I print or copy from my PDF?

The file probably has restrictions. Load it here and they are removed, if you have the right to change the file.

Is the file uploaded?

No. Everything happens in your browser and neither the file nor the password leaves your computer.
