Protect a PDF with a password.

The password is set in your browser, so neither the file nor the password is sent anywhere. Whoever opens the file has to type the password.

How to password-protect a PDF

  1. Open the PDF.

    Drop it on the page.

  2. Choose a password and rules.

    Type the password twice and decide whether printing, copying and editing are allowed.

  3. Protect and download.

    You get a new PDF that needs the password to open.

How the protection works

The file is encrypted with AES-256, the strongest encryption the PDF format supports. Without the password it cannot be opened. The rules for printing, copying and editing are followed by most PDF readers, but they are no real protection against someone who already has the password.

Keep this in mind

  • The password cannot be recovered. If you forget it the file cannot be opened, so keep it somewhere safe.
  • Choose a long password that is not a word from a dictionary.
  • Keep the original file if you may need it without a password.
  • Send the password a different way than the file.

Good to know

  • A PDF that already has a password has to be unlocked first, use Unlock PDF.
  • The PDF engine (about 25 MB) is downloaded the first time you use the tool.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about protecting PDFs

How do I password-protect a PDF?

Open the file here, type a password twice and click Protect PDF. You download a new file that needs the password to open.

Which encryption is used?

AES-256, the strongest the PDF format supports.

Can someone guess my password?

A long, random password is practically impossible to guess. A short or common word can be guessed, so choose a long one.

Is the file or the password uploaded?

No. Everything happens in your browser and neither the file nor the password leaves your computer.
