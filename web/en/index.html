Edit text in any PDF, right in your browser.

The free PDF editor that never uploads your file. Click a line, type, download.

The editor (about 25 MB) loads the first time you use it, then it is cached.

How it works

  1. Open your PDF.

    Drop it on this page. Every line of text becomes clickable.

  2. Click a line and type.

    Change the text, font, size or colour. Use Add text to put new text anywhere.

  3. Download.

    You get a normal PDF with your changes. Images, links and form fields stay as they were.

Find and replace

Need to change a date, a name or an invoice number that appears on every page? Press Ctrl/Cmd+F, type what to find and what to replace it with, and Retypee changes every match in one go. A live counter shows how many matches there are before you commit, and Undo brings everything back.

Private by design

Retypee is a web page, but the editing does not happen on a server. The PDF engine (PyMuPDF) is downloaded into your browser from a CDN (jsDelivr) – only the engine, never your file – and your file is opened and edited in your device's memory. Nothing is uploaded or stored, and closing the tab forgets it. You can check this in your browser's network tab.

The downloaded PDF also has its metadata removed: title, author, creator app, dates, and the file ID.

Good to know

  • Text does not reflow. PDFs store text at fixed positions, so lines are edited one at a time. Longer text runs further right; use Squeeze to fit or shorten it.
  • Scanned PDFs have no text. Run OCR first (for example with ocrmypdf), then open the result.
  • Fonts may differ slightly. PDFs usually embed only the letters they use. If a letter you type is missing, Retypee uses a fitting built-in font. Use Add font to give it the original .ttf or .otf for an exact match.
  • Rotated or vertical text and password-protected PDFs are not supported yet.

Questions

Is my PDF uploaded anywhere?

No. Retypee runs inside your browser tab. Your PDF is opened and edited in your device's memory, and nothing is sent to a server or stored. Only the editing engine is downloaded (from a CDN), never your file. Closing the tab forgets it.

Can I edit a scanned PDF?

Not directly. A scanned PDF is a picture of text, so there is no text to edit. Run it through OCR first (for example with ocrmypdf) and then open the result in Retypee.

Why does my edited text look slightly different?

PDFs usually embed only the letters they use. If the original font does not contain a letter you typed, Retypee looks for the same font among the fonts you added, and otherwise falls back to Helvetica, Times or Courier in the closest style. Use Add font to give it the original font file for an exact match.

Does the edited PDF keep its metadata?

No. The downloaded file has its metadata removed: title, author, creator app, dates, XMP data and the file ID. The visible content, images, links and form fields are not touched.

Will longer text reflow the paragraph?

No. PDFs store text at fixed positions, not as paragraphs, so lines are edited one at a time. If new text is longer it runs further right; use Squeeze to fit or shorten it.
