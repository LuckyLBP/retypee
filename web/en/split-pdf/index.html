Split a PDF into several files.

Choose how to split: page by page, in your own ranges or with the same number of pages in each file. You get a ZIP file with the result.

How to split a PDF

  1. Open the PDF.

    Drop it on the page. The number of pages is shown.

  2. Choose how to split it.

    Every page on its own, your own ranges like 1-3, 4-6, 7-, or every Nth page.

  3. Split and download.

    If there are several parts you get a ZIP file. If there is only one part you get a PDF straight away.

How to write ranges

  • 1-3 makes a file with pages 1, 2 and 3.
  • 7- means from page 7 to the end.
  • Write several ranges with commas: 1-3, 4-6, 7- gives three files.
  • A single page number, such as 5, gives a file with just that page.

Common uses

  • Split a scanned stack into one document per page.
  • Take a combined document apart into chapters.
  • Send only one part of a large PDF.

Good to know

  • The parts are named after the original file and the page numbers, such as report-1-3.pdf.
  • If you want certain pages in a single file, use Extract pages.
  • Password-protected PDFs have to be unlocked first.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about splitting PDFs

How do I split a PDF into several files?

Open the file, choose whether to split page by page, in your own ranges or every Nth page, and click Split PDF. You get a ZIP file with the parts.

How do I split a PDF in two?

Choose your own ranges and type something like 1-5, 6-. You get one file with pages 1–5 and one with the rest.

Is the file uploaded?

No. The split happens in your browser and the file never leaves your computer.

What is the difference between Split PDF and Extract pages?

Split PDF gives several files at once. Extract pages gives a single new PDF with the pages you pick.
