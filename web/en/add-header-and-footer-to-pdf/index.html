Header and footer in a PDF – with page numbers and date.

Write text at the top and bottom of every page, on the left, in the middle and on the right. Insert page number, date and file name with a code, and see the result on the first page.

How to add a header and footer

  1. Open the PDF.

    Drop it on the page.

  2. Write the texts.

    Six boxes: left, middle and right, top and bottom. Use the codes for page number, page count, date and file name.

  3. Add and download.

    The text is placed on every page of the new PDF.

The codes you can write

  • {n} becomes the page number.
  • {total} becomes the number of pages, for example in Page {n} of {total}.
  • {date} becomes today's date, as YYYY-MM-DD.
  • {file} becomes the file name without its extension.

Running numbers and Bates numbers

With First number and Digits you get running numbers such as ACME-000123, which is common when documents are marked for a review or a court case. Write ACME-{n}, set the first number and six digits.

Good to know

  • If you only want page numbers, Page numbers is simpler.
  • The text is written in Helvetica, so accented letters work but emoji do not.
  • Skip the first page if the cover page should be left clean.
  • If the pages already have a header the new one goes on top, so make sure they do not collide.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about headers and footers in PDFs

How do I add a footer to a PDF?

Open the file here, write the text in one of the boxes under Footer and click Add. The text lands at the bottom of every page.

Can I get the date and page number automatically?

Yes. Write the codes {date} and {n}, and they are filled in on every page.

Can I make Bates numbers?

Yes. Write for example ACME-{n}, choose the first number and the number of digits, and every page gets its own running number.

Is the file uploaded?

No. Everything happens in your browser and the file never leaves your computer.
