Remove metadata from a PDF – before you share it.

A PDF often carries more than you see: who made it, with which program and when. Clear it with one click.

How to remove metadata from a PDF

  1. Open the PDF.

    You see straight away which details it contains.

  2. Click Remove metadata.

    Title, author, subject, keywords, app, dates, XMP data and the file ID are cleared.

  3. Download.

    The table afterwards shows what is gone. The content itself – text, images, links – is untouched.

What is metadata in a PDF?

Metadata is information about the file, not in it: title, author, subject, keywords, which program made it and when it was created or changed. It comes in two forms, a classic information block and XMP, which can hold more. On top of that every file has its own ID.

What gets cleared

  • Title, author, subject and keywords.
  • The app and the PDF producer.
  • Created and modified dates.
  • XMP metadata for the document, the pages, the images and the fonts.
  • Page thumbnails and the names of people who wrote comments.
  • The file ID, which is replaced with a new random one.

Good to know

  • Text, images, links, form fields and attachments are not touched.
  • Metadata is not the content. If your name appears in the text itself it is not removed – use Redact PDF for that.
  • The editing engine (about 25 MB) is downloaded the first time you remove metadata.
  • Password-protected PDFs have to be unlocked first.

Your files never leave your device

This tool runs in your browser. The file is read into your device's memory, processed there and saved as a new file on your computer. Nothing is sent to a server.

Questions about PDF metadata

How do I remove the author from a PDF?

Open the file here and click Remove metadata. The author, app, dates and other details are cleared, and you can check the result in the table.

Does the look of the PDF change?

No. Only the information about the file is removed. The pages look the same.

Does it remove everything that could identify me?

It removes metadata, but not what is in the document's text or images. Read the file through and Redact PDF anything sensitive.

Is the file uploaded?

No. Everything happens in your browser and the file never leaves your computer.
